# Oathwise website

The public website of the Oathwise app, served by GitHub Pages at
https://oathwise.topjow.org/ (custom domain; see `CNAME`)

* `/` — about the app
* `/privacy/` — Privacy Policy (for Google Play and the App Store)
* `/terms/` — Terms of Use
* `/support/` — Help and support (support@topjow.org)
* `/content/` — study content updates the app downloads
  (`manifest.json`, current officials, alerts and guide)

This repository is generated by the "Publish site and content" workflow of
the app's repository. Do not edit it by hand: changes here are overwritten
by the next publish.
